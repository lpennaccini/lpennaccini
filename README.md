## Utility di ricerca in file XML

Lo script `xml_word_search.py` permette di cercare una parola all'interno di tutti i file XML presenti in una cartella. L'interfaccia grafica consente di selezionare la cartella, specificare la parola da cercare e visualizzare i risultati delle occorrenze trovate.

Esecuzione:

```bash
python xml_word_search.py
```

Se eseguito in un ambiente privo di interfaccia grafica potrebbe non funzionare correttamente.
